Penjelasan Kode :
Pada kode yang saya pakai saya menggunakan 1 Class dan 1 main : file Classs dan File main. Program ini ibarat sebuah catatan mendata film-film yang sedang tayang di bioskop. Program dibagi menjadi dua bagian: bagian pertama adalah formulir cetakannya (kelas Film), dan bagian kedua adalah petugas pencatatnya (fungsi main). Formulir ini mencatat 6 informasi penting untuk setiap film, yaitu kode ID, judul, jenis cerita (genre), sutradara, durasi menit, dan harga tiketnya. Begitu program pertama kali dinyalakan, sistem otomatis sudah mengisikan dua contoh data film awal yaitu Inception dan Interstellar ke dalam daftar simpanan.
Setelah itu, layar akan menampilkan menu pilihan angka 1 sampai 5 yang terus muncul berulang-ulang sampai kita memilih untuk selesai:
- Pilih 1 (Lihat Data): Layar akan memajang seluruh daftar film yang tersimpan beserta rincian lengkapnya secara rapi.
- Pilih 2 (Tambah Film): Kita diminta mengetik data film baru mulai dari judul hingga harga tiket, lalu sistem akan memasukkannya ke antrean daftar paling bawah.
- Pilih 3 (Ubah Data): Kita diminta mengetik kode ID film yang mau diganti. Sistem akan mencari film tersebut; jika ketemu, kita bisa mengetikkan data barunya untuk menimpa data yang lama.
- Pilih 4 (Hapus Film): Sistem meminta kode ID film yang ingin dibuang. Begitu kodenya cocok, film tersebut langsung dihapus permanen dari daftar.
- Pilih 5 (Cari film) : hanya pajangan saja
- Pilih 6 (Keluar)
